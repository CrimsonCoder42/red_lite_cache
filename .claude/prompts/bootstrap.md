═══ DECISIONS — MADE (D-002…D-022). Log each as its D-id in doc/DECISIONS.md with the alternative from the assessment and why it lost. ═══
D-002 Store: plain map[string]entry + sync.RWMutex per sheet. No sync.Map. No sharding until a benchmark in doc/ shows contention.
D-003 Expiry: expiresAt in the entry, checked lazily on Get/Has; ONE janitor goroutine per process sweeps every sheet every REDLITE_CACHE_JANITOR_INTERVAL; ttl 0 = no expiry. Expiry is broadcast as invalidate{key} to collaborators (fixes K3/R5) — batched per janitor pass, not per key.
D-010 Protocol version: `version` field on `open` (int, omitempty, absent = 1); the open reply carries `protocol_version`. Path stays /ws. Replicas use /replica.
D-011 WebSocket library: github.com/coder/websocket. Reason: ctx on every call, concurrent writes serialised, zero deps for the reader. gorilla lost on the write pump we would otherwise own.
D-012 Promotion fencing: an epoch (uint64) owned by the leader, persisted when persistence is on, incremented by a replica on promotion. Every replicate frame, every heartbeat, every `open` reply and every reader write carries it. A leader that receives a frame with a higher epoch logs Warn and steps down to replica of that sender. A reader that is told a lower epoch than it has seen refuses the connection and fails over. The Postgres advisory-lock variant goes to doc/TODO.md.
D-013 Sheet lifecycle: a sheet is never deleted because its last collaborator left. With REDLITE_SHEET_AUTOCREATE=true (the v1 default, for backendAdvo compatibility) the first `open` creates it and logs Warn "Sheet: autocreated"; with the flag false only the registry (S6 API) creates sheets and `open` of an unknown sheet fails `sheet not found`. Password hashes are part of replicated state (fixes K12).
D-014 Ordering: one sync.Mutex per sheet around apply + enqueue-to-every-collaborator. Broadcast goes to a bounded per-connection send queue (REDLITE_CONN_SEND_QUEUE, default 256); a full queue closes that connection (it resyncs on reconnect). No goroutine per sheet.
D-015 Persistence stack: github.com/jackc/pgx/v5 + pgxpool; sqlc v2 generating into db/sqlc/<pkg> with sql_package pgx/v5, emit_json_tags, emit_interface, emit_empty_slices, the same overrides backendAdvo uses (uuid→google/uuid, timestamptz→time.Time, jsonb→json.RawMessage); golang-migrate for db/migration, applied at boot when REDLITE_PERSIST_ENABLED=true. Query packages per D-019: db/query/{registry,entries,cluster,audit}. One `db.Store` wrapping the pool and the generated Queries, the way backendAdvo/db/sqlc/store.go does, with ExecTx.
D-019 Postgres role (doc/persist/postgres_role.md): control plane + durable copy, never the read/write path. Tables in 000001: projects, api_keys (sha256 hash, prefix, revoked_at), sheets (project_id, name, bcrypt hash), cluster_state (epoch, leader_instance), cache_entries (UNLOGGED unless REDLITE_PERSIST_LOGGED=true), audit_events (partitioned by month, BRIN on at). sqlc packages: registry, entries, cluster, audit. No pg_cron, no pgcrypto, no RLS, no GIN on value, no extensions beyond uuid-ossp.
D-020 Secrets hashed in Go only (bcrypt for sheet passwords, sha256 for API keys); Postgres stores hashes and never receives plaintext.
D-021 Control bus: after a registry commit the admin API NOTIFYs `redlite_control` with a reference payload; every instance LISTENs on one dedicated conn and re-reads the row; the cleaner tick is the fallback. Never data on NOTIFY. Off when persistence is off.
D-022 Election: REDLITE_ELECTION=epoch (default, D-012) | advisory (pg_try_advisory_lock on a dedicated conn decides the leader; the epoch still fences). Agent D implements both; the advisory path is tested only when REDLITE_TEST_DATABASE_URL is set.
D-016 Reader value handling: the reader stores json.RawMessage; `Get(key string, target any) bool` decodes into the caller's type (one pass, isolated copy); the old `Get(key) (any, bool)` stays as `GetRaw`. The nine backendAdvo methods keep their signatures (request.md CONTRACTS); `Get` is the one exception and is documented in doc/release.md as the S7 change.
D-017 Testing stack: stdlib testing + httptest, no testify. Integration harness in testing/integration/harness.go: StartLeader(t) and StartReplica(t, leader) on :0, each test its own sheet name, t.Cleanup stops everything. Persist tests use REDLITE_TEST_DATABASE_URL and a per-run schema; absent → t.Skip("SKIPPED: persist (no REDLITE_TEST_DATABASE_URL)").
D-018 Dev loop mirrors backendAdvo: .air.toml (build ./cmd/redlite into ./tmp/main, exclude _test.go), Makefile with the same target names where they mean the same thing (server, dev, test, sqlc, migrateup, migratedown, createdb, dropdb, postgres, network, db_reset, fresh_start) plus dev-pair (leader :8091 + replica :8092 under air, so my local advo_cache on :8081/:8082 is untouched) and bench. docker-compose.yml: postgres:16-alpine + leader + replica (backendAdvo runs 15; target >=15).
