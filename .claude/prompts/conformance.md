═══ THE CONFORMANCE TESTS (each a named test; each mirrors something backendAdvo does today) ═══
C1 ReadThroughCachesOnce: 3 readers, cachedOne on one key, the fake DB loads once per instance on first miss, zero times after (per-instance miss is expected — the local map is per process; say so in the plan).
C2 WriteInvalidatesEverywhere (assert_write_invalidates): read on all 3 → write through instance 1 → invalidateDomain once → read on 2 and 3 misses and reloads the new row — WITHOUT the second sweep. This is the test that retires secondSweepDelay.
C3 ReadThroughRaceNeverRecaches (R6 at consumer level): instance 2 is mid-load of the OLD row when instance 1 writes + sweeps; instance 2's Set must not land a stale value readable by anyone; prove with 200 iterations.
C4 PrefixSweepScope: fill 40 corpus shapes for 3 profiles; invalidateDomain(root, p1) removes exactly p1's keys of that root on all readers, nothing of p2/p3, nothing of other roots; record keys (<entity>:record:<id>) untouched.
C5 SuffixSweep: user:<uuid>:<tenant>:permissions for 3 tenants → DeleteSuffix(":permissions") removes all three, leaves user:<uuid>:<tenant>:profile.
C6 BothProfiles: invalidateDomainBoth(owner, requester) clears both heads; uuid.Nil requester skipped.
C7 TTLBounds: TTLAnalytics=5 min entry expires on every reader (fast clock via config: set REDLITE_CACHE_TTL small or use the harness clock) and the fake DB is loaded again after expiry; TTL 0 never expires.
C8 DisconnectRetiresDroppedSweeps (the DROPPED SWEEPS workaround): instance 2 disconnected; instance 1 writes + sweeps; instance 2 issues its own sweep while down; reconnect → instance 2's first read misses and reloads; no stale read at any point; the consumer did not queue anything itself.
C9 BootWhileCacheDown (main.go:118): reader.New with the leader down returns a usable reader, reads miss (DB path), connects when the leader appears; the consumer never needed Fatal.
C10 ErrorsNeverCached: a loader error is returned and not stored; the next call loads again.
C11 CursorKeysDistinct: two pages of the same list with different cursors are different keys and both are swept by one invalidateDomain.
C12 V1CompatSurface: every v1compat method against a live leader, including Get returning map[string]any for an object and the __NULL__ string for a null placeholder.
C13 KeyModeParity: C1–C6 again with REDLITE_ADMISSION=key and a registered project + key.
B1 BenchSweepRealShapes: DeletePrefix("<root>:patient:<uuid>") with 10k keys spread over 50 profiles × 8 roots using corpus shapes, current index vs a two-segment index you add behind a build-free switch (not a flag in prod — implement the two-segment index as the index if it wins; keep the first-segment code path only if it loses). benchstat, count=6, in the report; decision logged as D-037 with numbers.
